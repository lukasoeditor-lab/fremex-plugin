# FREMEX · Estúdio de edição para Claude Code

**FREMEX · The Creative Evolution.** Plugin para Claude Code que transforma o Claude num editor de vídeo: você manda o vídeo, diz como quer, e ele corta, legenda, reenquadra, trata o áudio, narra, anima, exporta e entrega.

## Instalar

```bash
claude plugin marketplace add lukasoeditor-lab/fremex-plugin
claude plugin install fremex@fremex
```

Abra uma nova sessão do Claude Code e rode `/fremex:setup`.

Detalhes, habilidades e custos: [plugins/fremex/README.md](plugins/fremex/README.md).

*Produto independente. A FREMEX não tem vínculo com a Anthropic, a HeyGen, a Remotion, a ElevenLabs ou o VoiceStudio.*
